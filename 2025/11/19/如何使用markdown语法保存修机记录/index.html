如何使用markdown语法保存修机记录

前言

  • Markdown作为一种标记语言,易学易读易写,既适合平常做笔记,也可使用渲染工具将其渲染为网页,做个人博客。
  • 我们采用Markdown来写修机记录或者专题分享,可供大家随时查阅,亦或是做强做大,做一个可以记录技术中心各种内容的平台。
  • 后期如果大家有兴趣的话,可以出搭建个人博客的教学,这也是基础。

一.Markdown使用

Reference: https://roc-mountain.github.io/Markdown/

1.Markdown是什么？

  • Markdown的目标是成为一种适用于网络的书写语言，实现「易读易写」。可读性，无论如何，都是最重要的。

  • 一份使用 Markdown 格式撰写的文件应该可以直接以纯文本发布，并且看起来不会像是由许多标签或是格式指令所构成。

  • Markdown 的语法受到一些既有 text-to-HTML 格式（包括 Setext、atx、Textile、reStructuredText、Grutatext 和 EtText）以及纯文本电子邮件的格式的影响，全由一些符号所组成，这些符号经过精挑细选，其作用一目了然。

  • Markdown 的写法兼容HTML。需要注意HTML标签的类型：在 HTML 区块（块元素）标签间的 Markdown 格式语法将不会被处理（如：div,table,p）。HTML 的区段（行内元素）标签(如：span,a,img)可以在 Markdown 的段落、列表或是标题里随意使用。如果比较喜欢 HTML 的 <a> 或 <img> 标签，可以直接使用这些标签，而不用 Markdown 提供的链接或是图像标签语法。

  • 通常情况下,用 Markdown 语法编写的文件的后缀名为.md。

2.Markdown编写工具

Typora是一款 所见即所得 (WYSIWYG) 的 Markdown 编辑器。

  • 实时预览：输入 Markdown 语法后立即渲染成排版效果。
  • 支持多种导出格式：如 PDF、HTML、Word 等。
  • 内置大纲视图：方便快速定位和跳转。
  • 数学公式支持：兼容 LaTeX 语法。
  • 代码高亮：支持多种编程语言的语法高亮。
  • 主题与样式：可自定义 CSS，打造个性化排版。

  • 免费开源，跨平台支持
  • 内置 Git 集成，方便版本控制
  • 丰富的扩展市场，支持多种语言和框架

  • 可自定义主题与快捷键

Markdown 支持两种标题的语法：类 Setext 和 类 Atx。

3.2 段落和换行

  • 段落由一个或多个连续文本行组成，前后需有一个以上的空行。
  • 段落内可强制换行：在换行处输入两个以上空格再回车。
  • 普通段落不应使用空格或制表符缩进，否则会变为代码区块。

3.9图片

  • 图片和链接的写法相似，只是在链接写法的前边加一个叹号 （!）

3.11 表格

Markdown 也可以制作表格，用分隔符（|）确定表格是几列，用换行确定是几行，用冒号（:）确定内容对齐方式（只有左侧有冒号-左对齐,只有右侧有冒号-右对齐，两侧都有冒号-居中）。

  • 使用github的静态网站托管服务,将静态网页文件上传至GitHub，并通过GitHub提供的域名访问。这种方式不仅成本低，而且管理方便，适合个人开发者和小型项目。
